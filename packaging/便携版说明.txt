AI Gateway 0.3.10 便携版

本版本将配置字段说明收进信息图标，支持鼠标、点击和键盘查看，同时保留关键错误与风险状态常显。

1. 解压整个 ZIP 后，直接运行“AI Gateway.exe”，无需安装或卸载。
2. 便携版与安装版共用 %APPDATA%\com.ai-gateway.desktop 下的数据库，以及 Windows 凭据管理器中的中转密钥。
3. 安装版与便携版不能同时运行，否则两者共享的本地监听端口会冲突（默认 127.0.0.1:8765）。启动前请先退出托盘中的旧实例。
4. 更新便携版时，先退出托盘程序，再覆盖便携目录。删除便携目录不会删除已有中转配置或 Windows 凭据。
5. 0.2.8 修复了旧版未实际写入 Windows 凭据管理器的问题。旧版已经丢失的 API Key 无法自动恢复，请在本版本中重新填写一次；之后安装版与便携版均可持续读取。
6. 如果移动了便携目录，请在配置中心重新保存开机启动设置，使启动路径指向新的位置。
7. 跨电脑迁移请使用“中转管理”中的加密导出和导入功能，便携目录不保存明文 API Key。
8. 删除便携版前，请先在“Codex 接入”中切回 OpenAI 官方模式，确保共享 custom Provider 不再指向本地网关。
9. AI Gateway 只管理 Codex 的 config.toml，不读取或修改 auth.json；官方与第三方都使用 requires_openai_auth=true，ChatGPT 登录态会持续保留。
10. 官方模式与第三方模式切换后需要完全退出并重新启动 Codex；AI Gateway 内部切换第三方中转无需重启 Codex。
11. “统一会话历史”只修改会话首条 Provider 元数据和本地索引，归档状态及聊天正文保持不变；迁移前必须完全退出 Codex。
12. CC-Switch 与 AI Gateway 不应同时接管 custom Provider。使用本程序切换前，请先关闭 CC-Switch 路由。
13. 用量统计会只读扫描 Codex sessions/archived_sessions 中的 token_count，官方直连仍完全绕过 AI Gateway，auth.json 不会被读取或修改。
14. 自动切换中转默认关闭；内部熔断只作提示，新请求仍会访问当前中转。模型、分组、容量和账号并发限制始终只重试当前中转。
15. 第三方用量优先采用上游 usage，缺失时使用 tiktoken 估算；重试产生的每次实际上游调用分别计量并标明数据质量。
