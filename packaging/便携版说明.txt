AI Gateway 0.2.4 便携版

1. 解压整个 ZIP 后，直接运行“AI Gateway.exe”，无需安装或卸载。
2. 便携版与安装版共用 %APPDATA%\com.ai-gateway.desktop 下的数据库，以及 Windows 凭据管理器中的中转密钥。
3. 安装版与便携版不能同时运行，否则本地端口 127.0.0.1:8765 会冲突。启动前请先退出托盘中的旧实例。
4. 更新便携版时，先退出托盘程序，再覆盖便携目录。删除便携目录不会删除已有中转配置。
5. 如果移动了便携目录，请在配置中心重新保存开机启动设置，使启动路径指向新的位置。
6. 跨电脑迁移请使用“中转管理”中的加密导出和导入功能，便携目录不保存明文 API Key。
